# Password dictionary for offline pattern matching.
#
# Used by `rtt password` to decide whether a candidate is a decorated dictionary
# word. Not a cracking list; the strength checker never attempts to use it
# against anything, it only looks up substrings.
#
# Deliberately small and hand-written rather than a real 14-million-line leaked
# list: the point is to catch the predictable constructions, and a curated set
# gives fewer false positives than brute substring matching.
